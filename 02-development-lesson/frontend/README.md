# Snake Arena Classic — Frontend

Frontend implementation for Snake Arena, a classic Snake game with authentication, persistent scoring, and leaderboard.

> [!NOTE]
> The full product specifications and user stories are documented in [**`docs/spec.md`**](../docs/spec.md).

## Local Development

To run the frontend application locally, you will need Node.js or Bun:

```sh
npm install
npm run dev
```

Or using Bun:

```sh
bun install
bun run dev
```
